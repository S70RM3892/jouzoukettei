# jouzoukettei — 有機構造決定パズル

京大化学の有機（大問3の構造決定）で使う「条件から候補を絞り込む推論」を反復訓練するブラウザゲーム。
仕様は Claude Docs の「有機構造決定パズル 仕様書」。

| モード | 内容 | 問題数 |
| --- | --- | --- |
| 絞り込み型 | 分子式と手がかりカードから、候補を消して1つに決める（C₅以下の脂肪族） | 20 |
| 大問型 | C₁₂〜C₂₀ のエステル・アミド・ペプチドを加水分解 → 切れた結合の数 → 断片ごとに絞り込み → 部分加水分解で組み立て | 8 |
| 数え上げ型 | 条件を満たす構造異性体と立体異性体の数を答え、全異性体で答え合わせ | 10 |
| 高分子型 | 平均分子量から重合度と結合の数を計算 → 加水分解で得た単量体を絞り込む（ナイロン66・ナイロン6・PET・ポリ乳酸・ポリ酢酸ビニル・アラミド） | 6 |
| 京大レベル | 京大の過去問の答え X を同じ手順で問題化した「再現」と、その難易度帯に入る自動生成の大問。水素付加量・燃焼分析・つなぎ方の数の計算つき。毎朝5時に入れ替わる | 11＋12 |

## 遊び方

`dist/index.html` をブラウザで開くだけ。サーバーもネット接続もいらない（フォントだけ Google Fonts から読む）。
`dist/` は GitHub Actions が自動で生成してコミットする。

1. 問題を選ぶ（難易度 ★1〜★3、または「おまかせ」）
2. 手がかりカードをタップして結果を見る。問題ごとに「最少で何枚あれば決まるか」を表示し、それより多く開いた分だけ1枚 −10 点
3. 矛盾する候補を自分で消す（左右スワイプか「消す」）。自動では消えない
4. 残り1つで「確定」。誤答なら矛盾したカード、根拠なしで消した候補は消すべきだったカードが出る
5. 間違えたカードの種類が「復習リスト」に溜まり、おまかせ出題で多めに出る

23時〜5時はプレイできない（仕様書の運用ルール）。

化学処理（RDKit）はビルド時に Node で行い、ブラウザには前計算した構造式SVGと判定結果だけを埋め込む。
仕様書ではブラウザで RDKit.js を CDN から読む案だったが、wasm 読み込みが不要になり、スマホでも一瞬で開けてオフラインでも動くのでこちらにした。

## 問題を足す

```sh
npm install
npm test          # 判定ロジックのテスト + 全問題の検証
npm run build     # dist/index.html を作り直す
```

検証スクリプトが確認すること（1つでも落ちた問題は収録しない）:

1. 全候補の分子式が `formula` と一致する
2. 候補に重複がない（canonical SMILES で比較）
3. 全手がかりを適用すると、候補が `answer` の1つだけ残る
4. どの手がかりも、単独で候補を1つ以上消す
5. 手がかりの `result` が、正解の構造に実際にカードを当てた結果と一致する
6. カードが適用できない構造（例: C=C を持つ候補に KMnO₄）を含まない
7. 大問型: X の加水分解生成物と断片が一致し、原子の収支（X ＋ n H₂O）が合う。組み立ての候補はどれも同じ断片に分かれる
9. 高分子型: 繰り返し単位 ＋ `bondsPerUnit` H₂O と単量体の合計で原子の収支が合う
8. 数え上げ型: 母集団が重複なく所定の数そろっていて、答えの数が `expect`（教科書の数）と一致する

## 自動生成のしくみ（京大レベル）

1. **断片ライブラリ**: アルコール（不飽和のものと環状のものを同じ候補集合に）・ヒドロキシ酸・ジオール・カルボン酸・芳香族カルボン酸・ピリジンカルボン酸・三価カルボン酸・フェノール・アミン・カルボニル化合物・環状ケトンなど 19 分類について、分子式ごとに構造異性体を全部列挙する（環は五員環・六員環だけ）。候補集合に漏れがないので「全部考えたか」が試される
2. **型**: ジカルボン酸のジエステル／ジオールのジエステル／エステル＋アミド／ジアミド／グリセリンのトリエステル／ビニルエステル／ヒドロキシ酸でつないだエステル（2020 型）／三価カルボン酸のエステルとアミド（2009 型）／環状ケトンのエノールエステル（2003 型）の 9 型。京大の X 11 題（2003・2006・2007・2008・2009・2010・2013・2016×2・2017・2020）はすべてこの 9 型のどれかで作れる
3. **手がかり**: 断片ごとに「答えがちょうど1つに決まる最小のカードの組」を総当たりで探す。1枚で決まるカードは使わない（京大と同じく、条件を組み合わせないと決まらないようにする）。カードで決められない構造は出題しない
4. **組み立て**: つなぎ方が複数あれば、部分加水分解の生成物や不斉炭素で決めさせる
5. **計算**: X の水素付加量（標準状態の体積から C=C の数）、断片 1 つの燃焼分析（CO₂・H₂O の質量から分子式）、X の分子式を伏せて分子量と燃焼分析から求めさせる（2020・2024 型）、つなぎ方だけが違う X の候補の数（2001 型）。丸めた数値から分子式が一意に戻ることを確かめてから出す。燃焼分析の選択肢は分子量が同じ組（CH₄ ⇄ O）にして、分子量だけでは選べないようにしている
6. **難易度**: 候補数の情報量・手がかりの数と種類・立体・与えられた規則・組み立て・計算・炭素数から点数をつける。京大の X を同じ手順で問題化して測り、**京大の下位 25% 〜 最大の 1.25 倍** に入ったものだけ採用する

7. **ブレ**: 試料の質量（3〜30 g、5〜40 mg を有効数字 3 けたで）、問題文の言い回し、X の分子式を伏せるか、どの計算段階を出すか、を毎回変える。同じ型・同じ分類の組み合わせは 1 日 1 問まで
8. **新しいカード**: 水の付加（マルコフニコフ則。2005・2002 型の「与えられた規則」）

前の版（6 型）と比べた多様性（難易度帯に入った 150 題ずつ、同じ乱数の種）:

| | 前の版 | 今の版 |
| --- | --- | --- |
| 型 | 6 | 9 |
| 型×断片の分類の組み合わせ | 30 | 56 |
| 断片の分類 | 14 | 19 |
| X どうしの平均類似度（Morgan 指紋の Tanimoto、低いほど多様） | 0.247 | 0.221 |
| 脂肪族の環をもつ X | 0 | 38 |
| 計算段階の種類 | 2 | 4 |
| 問題文の言い回し | 4 | 73 |

### 当てる練習（後ろ向き検証）

どれも「その年より前のデータだけで、その年を当てる」形で測った。

| 対象 | 方法 | 結果 |
| --- | --- | --- |
| 出題要素（36 タグ・27 年分） | 出現頻度 / 減衰と間隔を調整したモデル / 前年コピー | 的中率（R 精度）52.0% / 51.5% / 37.9%（当てずっぽう 33.6%）→ 単純な出現頻度を採用 |
| 学習に使う年数（評価は 2020〜2026） | 1 / 4 / 8 / 12 / 16 / 20 年 | 39% / 46% / 51% / 52% / 54% / 54%。答えの年まで含めて数えても 57% なので、12 年あたりで頭打ち |
| 大問の型（9 型） | 一様 / 過去の型の割合 / 出題予測 / 半々 | 実際の型に付けた確率 11% / 8% / 13% / 10% → 出題予測を採用（検証できたのは 9 題だけなので差は参考程度） |
| エンジンの到達範囲 | 京大の設問 60 個をエンジンだけで解く | 60/60。残る未対応は 1 件（環状の糖の立体を区別したメチル化分析）。`npm run test:kakomon` で一覧が出る |

調整したモデルが単純な頻度に勝てないのは、年ごとの出題のばらつきが大きく、細かい調整が過去に合わせすぎになるため。勝った方を自動で選ぶようにしてある。

```sh
npm run forecast                   # 出題予測と後ろ向き検証
npm run generate -- 20260929 12    # 種 20260929 で 12 問（省略すると今日の日付）
```

GitHub Pages の workflow は毎朝 5:00（日本時間）に、その日の日付を種にして作り直して公開する。
リポジトリに 60 日間 push がないと GitHub が定期実行を止めるので、そのときは Actions 画面から有効に戻す。

## 京大の「与えられた規則」と立体

以前は扱えなかった出題要素を、規則として実装した。どれも京大の設問をエンジンだけで解かせて、答えと一致することを確かめてある。

| カード | 規則 | 出典 |
| --- | --- | --- |
| 小員環の水素化開環 | 三員環・四員環の C–C が1本切れる。小員環がいちばん残らない結合が切れる | 2025 III |
| 臭素付加（立体）・水素付加（立体） | Br₂ はアンチ付加、白金触媒の H₂ はシン付加。E/Z から生成物の立体異性体が決まる | 2024 III(b) |
| 立体異性体の数・光学活性 | 鏡像異性体・メソ体・シス-トランスを区別して数える | 2002 III・2019 IV |
| 硝酸酸化（糖）・炭素を1つ減らす反応 | フィッシャー投影のアルドースから、立体を保って変換 | 2019 IV |
| イミドの穏やかな加水分解 | C(=O)–N–C(=O) の C–N が1本だけ切れる（どちらかは決まらない） | 2019 III(b) |
| 選択的アセチル化 | 同じ物質量の無水酢酸では第一級 OH だけ | 2010 III(a) |
| ニトロ化・臭素化・塩素化・スルホン化・臭素水 | 配向性（-NH₂・-OH > -NHCOCH₃・-OR > アルキル > ハロゲン、メタ配向の基）と立体障害 | 2018 III・2016・2010(b)・2009・2004 |
| ニトロ基の還元・アセチル化・ジアゾ化と還元・ジアゾ化と加熱・ジアゾカップリング | 合成経路をたどる（m-ブロモトルエンの合成など） | 2018 III・2001 III |
| エーテルの水素化分解 | Ar–O–Ar' + H₂ → Ar–OH + Ar'–H（両方の向き） | 2016 III(b) |
| エタノール中・メタノール中の平衡、アセタールの加水分解 | 五員環・六員環をつくれるアルデヒドは環状アセタール、つくれないものはジアルキルアセタール | 2026 III |
| アセトンによる保護 | 1,2 または 1,3 の OH の組。OH が3つ以上なら近い組 | 2020 IV |
| メチル化分析 | すべての OH をメチル化してからグリコシド結合だけを加水分解 | 2026 IV |
| 水の付加（マルコフニコフ則） | H は H の多い炭素に | 2005・2002 |

このうち臭素水・ニトロ化・選択的アセチル化・アセトン保護・臭素付加・立体異性体の数は自動生成の手がかりにも使う。
これで、今までカードで区別できず出題できなかった断片（クレゾール・エチルフェノール、ヒドロキシ安息香酸、アミノ安息香酸など）も問題にできるようになった。
