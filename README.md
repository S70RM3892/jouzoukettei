# jouzoukettei — 有機構造決定パズル

京大化学の有機（大問3の構造決定）で使う「条件から候補を絞り込む推論」を反復訓練するブラウザゲーム。
仕様は Claude Docs の「有機構造決定パズル 仕様書」。

| モード | 内容 | 問題数 |
| --- | --- | --- |
| 絞り込み型 | 分子式と手がかりカードから、候補を消して1つに決める（C₅以下の脂肪族） | 20 |
| 大問型 | C₁₂〜C₂₀ のエステル・アミド・ペプチドを加水分解 → 切れた結合の数 → 断片ごとに絞り込み → 部分加水分解で組み立て | 8 |
| 数え上げ型 | 条件を満たす構造異性体と立体異性体の数を答え、全異性体で答え合わせ | 10 |
| 糖の構造決定 | 二糖・三糖を、還元性・加水分解の生成物・メチル化分析・酵素の組み合わせで決める | 17 |
| 高分子型 | 平均分子量から重合度と結合の数を計算 → 加水分解で得た単量体を絞り込む（ナイロン66・ナイロン6・PET・ポリ乳酸・ポリ酢酸ビニル・アラミド・ポリメタクリル酸メチル・ポリプロピレン） | 8 |
| 京大レベル | 京大の過去問の答え X を同じ手順で問題化した「再現」と、その難易度帯に入る自動生成の大問。水素付加量・燃焼分析・つなぎ方の数の計算つき。毎朝5時に入れ替わる | 11＋12 |
| 異性体俯瞰型 | 分子式の構造異性体を環・三重結合まで全部候補にし、性質と反応の組み合わせで1つに決める | 28 |

## 知識確認と範囲のチェック

- `data/curriculum.json`: 高校化学（学習指導要領「化学」の有機化合物・高分子化合物）の内容を、教科書の節の順に 6 章 39 節に並べたもの。節ごとに、判定できるカードと練習できるモードを書く
- `problems/knowledge.json`: 一問一答（4択）397 問。すべての節に 10 問以上。まちがえた問題と未挑戦の問題が出やすく、2回続けて正解すると「覚えた」になる
- `problems/calc.json`: 入試の定番の計算 43 問（`scripts/calcdrill.js` が数値を変えて作る。けん化価・ヨウ素価・硬化油の H₂・等電点・電気泳動・イオンの比・ペプチドの分子量・窒素からタンパク質量・ビニロンのアセタール化・元素分析・重合度）。誤答はよくある間違い（×3 を忘れる、外れる水を引き忘れるなど）から作る
- `npm run test:coverage`（`npm test` にも入っている）: すべての節に知識確認があるか、節に書いたカードが実在するか、どの節にも入っていないカードがないかを確かめ、構造決定などの問題では練習できない節を一覧にする

構造決定などの問題では練習できず、知識確認だけで扱う節（7）: 石油と炭化水素の利用、セッケンと合成洗剤、熱硬化性樹脂、ゴム、機能性高分子、セルロースの利用、核酸。

## 糖

糖は α/β やグルコースとガラクトースの違いが立体だけなので、立体を落とす一般の判定では区別できない。`src/sugar.js` の略記 `sac:`（IUPAC の糖の略記に合わせる。例 `sac:Glc(a1-4)Glc` がマルトース、`sac:Glc(a1-2b)Fru` がスクロース、`sac:Glc{2,3,6}` が 2,3,6-トリ-O-メチルグルコース）で書き、還元性・加水分解・メチル化分析・酵素（マルターゼ・インベルターゼ・ラクターゼ・セロビアーゼ）を記号として判定する。
構造式は PubChem の α/β-D-グルコピラノース・ガラクトピラノース・β-D-フルクトフラノースから立体つきで組み立て、マルトース・ラクトース・セロビオース・スクロース・トレハロースで PubChem と一致することをテストで確かめている。
立体なしの構造でも、環状のヘミアセタール（グルコースなど）と –CO–CH₂OH（フルクトース）は還元性あり、グリコシド結合は加水分解されるものとして判定する。

「糖の構造決定」モード（`scripts/saccharide.js`）: 二糖 12 候補・三糖 9 候補から、2枚以上の手がかりで1つに決める 17 問。候補の下に結合の略記を出し、慣用名は答えたあとに出す。

シス-トランス異性のカードは、C=C に加えて環のシス-トランス（同じ環に、環の外の2つの置換基が異なる炭素が2つ以上）も判定する。
高分子型にポリメタクリル酸メチルとポリプロピレンを足した（8 問）。

## 条件を指定して出す

ホームの「条件を選ぶ」で、大問の型（10）・含めたい断片（19 分類）・難易度（6段階）・計算（X の分子式の燃焼分析・断片の燃焼分析・水素付加量・つなぎ方の数）・化合物どうしの関係・与えられた規則を選び、条件に合う大問を1問出す。

- 問題は Pages の毎朝のビルドで 300 問作りためる（`npm run generate -- pool <種> 300`、約5分）。型×難易度に偏りなく作る
- `dist/pool/<id>.json` に1問ずつ（構造式つき）、`dist/pool/index.json` に条件で選ぶための一覧を置き、画面は選んだ1問だけを読む。ページは重くならない
- 未正解の問題を優先して出す。ランキングの問題数には入れない
- 公開版（GitHub Pages）でだけ使える（ネットなしの HTML と claude.ai 版では在庫を読めない）

## 異性体俯瞰型

分子式の構造異性体を環・三重結合まで全部候補にし、性質と反応の手がかりを2枚以上組み合わせて1つに決める絞り込み問題（`scripts/survey.js`）。

- `data/survey.json`: 京大以外の国立大学の理系化学3年分の有機の出題要素を、問題文を写さずにタグと自分の言葉の要約にしたもの。タグの出た年数からカードの重みを決める
- 入試の答えの化合物を答えにした問題を先に作り、残りは分子式と答えを変えて作る
- 新しいカード: アセチリドの沈殿（末端の H–C≡C–）、水の付加（三重結合、O は H の少ない側）
- 3年分では京大のような難易度の物差しや出題予測は作れないので、候補の数と手がかりの数で3段階に分ける

```sh
npm run survey -- 20260930 28   # 作り直す（problems/survey.json）
```

## 難易度（6段階）

| 段階 | 目安 |
| --- | --- |
| 基礎 | 京大の答えの難易度の下位25% の 0.7 倍未満 |
| 標準 | 京大の下位25% 未満 |
| 京大下位 | 京大の中央値未満 |
| 京大平均 | 京大の上位25% 未満 |
| 京大上位 | 京大の最難未満 |
| 京大超え | 京大の最難以上 |

物差しは、京大の答え X 11 題を同じ手順で問題化して測った難易度の分布。大問の難易度は、候補の数・手がかりの数と種類・立体・与えられた規則・誘導体・化合物どうしの関係・計算・炭素数から計算する。
毎日の自動生成は6段階から2問ずつ出す。絞り込み型などの手作りの問題は、もとの ★1〜3 を基礎〜京大下位に当てる。

## ランキング・意見投稿・早解き対戦（オンライン）

claude.ai で開いたときは claude.ai の保存と部屋を使う。GitHub Pages（https://s70rm3892.github.io/jouzoukettei/）では Firebase（匿名ログイン＋ Cloud Firestore、無料の Spark プランで足りる）を使う。
Pages 版は端末（ブラウザ）ごとに匿名の参加者になり、ホームの「名前」で決めた名前がランキング・投稿・対戦に出る。

Firebase でさらに使えるもの（claude.ai 版でも同じ）:

- **今日のタイムアタック**: 毎朝5時に入れ替わる自動生成の大問から、日付で決まる1問（京大下位〜京大平均）を全員が解く。最初に開いた時刻から採点までを測り、その日の最初の採点だけを記録する（Firestore のルールで書き換えられない）。得点の高い順、同点なら速い順
- **みんなの間違い**: 全員の記録を足して、正答率の低い問題・いちばん間違える設問・間違えた手がかりカードを並べる。大問の採点画面には設問ごとの「みんなの正答率」が出る（2 回以上採点されたもの。記述は自己採点なので数えない）

最初に1回だけ設定する:

1. [Firebase コンソール](https://console.firebase.google.com/)でプロジェクトを作り、「ウェブアプリを追加」して表示される `firebaseConfig` を控える
2. Authentication →「ログイン方法」で **匿名** を有効にする。「設定」→「承認済みドメイン」に `s70rm3892.github.io` を足す
3. Firestore Database を作り、「ルール」にこのリポジトリの `firestore.rules` を貼って公開する（書けるのは自分の文書だけ）
4. 控えた `firebaseConfig` を `firebase.config.json` に書いてコミットする（今はプロジェクト `minhaya-3e7ee` の設定が入っている）。リポジトリ変数 `FIREBASE_CONFIG` があればそちらが優先。ウェブ用の設定は公開して問題ない値
5. Actions の pages を手動で走らせる（または main に push）

設定がないと、オンラインの3つは「使えない」と表示されるだけで、ほかは今まで通り動く。
手元で試すときも `npm run build` でこの設定が入る。`"emulator": "127.0.0.1"` を足すと Firebase Emulator Suite（auth 9099・firestore 8080）につなぐ。

## 京大形式（大問）

京大の大問と同じく、問題文と実験（あ）（い）…を最初に全部読んでから、問1〜に答える。

**問題文**
- 規則の段落: 教科書にない反応（選択的アセチル化、マルコフニコフ則、過ヨウ素酸など）を使う問題では、最初に規則として示す
- X の測定（燃焼分析・水素付加量）→ 化合物 A, B, … の実験 → 誘導体（「A を酸化すると D が得られた。D は…」）→ 化合物どうしの関係 → 部分加水分解
- **化合物どうしの関係**: 「B を KMnO₄ で酸化すると A が得られた」「C と D に水素を付加させると同じ化合物が得られた」など。
  `src/chain.js` が、断片それぞれの実験・誘導体の実験・関係を混ぜて、**全体を同時に考えたときに初めて1通りに決まる**手がかりの組を選ぶ
  （候補が4つ以上の断片には、それ自身か誘導体についての事実を2つ以上残す）。自動生成の6割以上がこの型
- 断片の分類（アルコールかどうか）は書かない。加水分解生成物であることと実験から判断させる

**設問**（京大に出る形だけ）
- X の分子式（燃焼分析、記述）、C=C の数（記述）
- 抽出: 加水分解後の混合物を希塩酸・NaHCO₃ 水溶液・NaOH 水溶液・エーテル層に分けるとき、各化合物がどこに入るか
- 断片の分子式（燃焼分析）、「実験（x）（y）の結果だけから考えられるものをすべて選べ」／何通りあるか
- 断片と誘導体の構造（選択。名前は採点後に出す）
- 条件を満たす構造異性体の数、X の不斉炭素の数、X w g から得られる断片の質量（有効数字3けた）、つなぎ方の数
- X の構造（断片を惜しい別の候補に替えて組み直した誤答つき）
- 理由の記述（抽出の理由、関係からわかること、酸無水物ができる理由）: 模範解答と見比べて自己採点

反応名の4択・加水分解で消費される水の量・単独の生成物予測は、京大の大問らしくないので外した。

各実験の「わかること」を開くと、その結果で決まる部分構造が出る（1回 −1点）。採点すると、問ごとに正解・根拠の実験・解説が出る。

## 遊び方

`dist/index.html` をブラウザで開くだけ。サーバーもネット接続もいらない（フォントだけ Google Fonts から読む）。
`dist/` は GitHub Actions が自動で生成してコミットする。

1. 問題を選ぶ（難易度 ★1〜★3、または「おまかせ」）
2. 手がかりカードをタップして結果を見る。問題ごとに「最少で何枚あれば決まるか」を表示し、それより多く開いた分だけ1枚 −10 点
3. 矛盾する候補を自分で消す（左右スワイプか「消す」）。自動では消えない
4. 残り1つで「確定」。誤答なら矛盾したカード、根拠なしで消した候補は消すべきだったカードが出る
5. 間違えたカードの種類が「復習リスト」に溜まり、おまかせ出題で多めに出る

23時〜5時はプレイできない（仕様書の運用ルール）。

## 問題を足す

```sh
npm install
npm test          # 判定ロジックのテスト + 全問題の検証
npm run build     # dist/index.html を作り直す
```

検証スクリプトが確認すること（1つでも落ちた問題は収録しない）:

1. 全候補の分子式が `formula` と一致する
2. 候補に重複がない（canonical SMILES で比較）
3. 全手がかりを適用すると、候補が `answer` の1つだけ残る
4. どの手がかりも、単独で候補を1つ以上消す
5. 手がかりの `result` が、正解の構造に実際にカードを当てた結果と一致する
6. カードが適用できない構造（例: C=C を持つ候補に KMnO₄）を含まない
7. 大問型: X の加水分解生成物と断片が一致し、原子の収支（X ＋ n H₂O）が合う。組み立ての候補はどれも同じ断片に分かれる
9. 高分子型: 繰り返し単位 ＋ `bondsPerUnit` H₂O と単量体の合計で原子の収支が合う
8. 数え上げ型: 母集団が重複なく所定の数そろっていて、答えの数が `expect`（教科書の数）と一致する

## 自動生成のしくみ（京大レベル）

1. **断片ライブラリ**: アルコール（不飽和のものと環状のものを同じ候補集合に）・ヒドロキシ酸・ジオール・カルボン酸・芳香族カルボン酸・ピリジンカルボン酸・三価カルボン酸・フェノール・アミン・カルボニル化合物・環状ケトンなど 19 分類について、分子式ごとに構造異性体を全部列挙する（環は五員環・六員環だけ）。候補集合に漏れがないので「全部考えたか」が試される
2. **型**: ジカルボン酸のジエステル／ジオールのジエステル／エステル＋アミド／ジアミド／グリセリンのトリエステル／ビニルエステル／ヒドロキシ酸でつないだエステル（2020 型）／三価カルボン酸のエステルとアミド（2009 型）／環状ケトンのエノールエステル（2003 型）の 9 型。京大の X 11 題（2003・2006・2007・2008・2009・2010・2013・2016×2・2017・2020）はすべてこの 9 型のどれかで作れる
3. **手がかり**: 断片ごとに「答えがちょうど1つに決まる最小のカードの組」を総当たりで探す。1枚で決まるカードは使わない（京大と同じく、条件を組み合わせないと決まらないようにする）。カードで決められない構造は出題しない
4. **組み立て**: つなぎ方が複数あれば、部分加水分解の生成物や不斉炭素で決めさせる
5. **計算**: X の水素付加量（標準状態の体積から C=C の数）、断片 1 つの燃焼分析（CO₂・H₂O の質量から分子式）、X の分子式を伏せて分子量と燃焼分析から求めさせる（2020・2024 型）、つなぎ方だけが違う X の候補の数（2001 型）。丸めた数値から分子式が一意に戻ることを確かめてから出す。燃焼分析の選択肢は分子量が同じ組（CH₄ ⇄ O）にして、分子量だけでは選べないようにしている
6. **難易度**: 候補数の情報量・手がかりの数と種類・立体・与えられた規則・組み立て・計算・炭素数から点数をつける。京大の X を同じ手順で問題化して測り、**京大の下位 25% 〜 最大の 1.25 倍** に入ったものだけ採用する

7. **ブレ**: 試料の質量（3〜30 g、5〜40 mg を有効数字 3 けたで）、問題文の言い回し、X の分子式を伏せるか、どの計算段階を出すか、を毎回変える。同じ型・同じ分類の組み合わせは 1 日 1 問まで
8. **新しいカード**: 水の付加（マルコフニコフ則。2005・2002 型の「与えられた規則」）

### 当てる練習（後ろ向き検証）

どれも「その年より前のデータだけで、その年を当てる」形で測った。

| 対象 | 方法 | 結果 |
| --- | --- | --- |
| 出題要素（36 タグ・27 年分） | 出現頻度 / 減衰と間隔を調整したモデル / 前年コピー | 的中率（R 精度）52.0% / 51.5% / 37.9%（当てずっぽう 33.6%）→ 単純な出現頻度を採用 |
| 学習に使う年数（評価は 2020〜2026） | 1 / 4 / 8 / 12 / 16 / 20 年 | 39% / 46% / 51% / 52% / 54% / 54%。答えの年まで含めて数えても 57% なので、12 年あたりで頭打ち |
| 大問の型（9 型） | 一様 / 過去の型の割合 / 出題予測 / 半々 | 実際の型に付けた確率 11% / 8% / 13% / 10% → 出題予測を採用（検証できたのは 9 題だけなので差は参考程度） |
| エンジンの到達範囲 | 京大の設問 61 個をエンジンだけで解く | 61/61。未対応の出題要素は 0 件（環状の糖の立体を区別したメチル化分析も解ける）。`npm run test:kakomon` で一覧が出る |

調整したモデルが単純な頻度に勝てないのは、年ごとの出題のばらつきが大きく、細かい調整が過去に合わせすぎになるため。勝った方を自動で選ぶようにしてある。

```sh
npm run forecast                   # 出題予測と後ろ向き検証
npm run generate -- 20260929 12    # 種 20260929 で 12 問（省略すると今日の日付）
```

GitHub Pages の workflow は毎朝 5:00（日本時間）に、その日の日付を種にして作り直して公開する。
リポジトリに 60 日間 push がないと GitHub が定期実行を止めるので、そのときは Actions 画面から有効に戻す。

## 京大の「与えられた規則」と立体

以前は扱えなかった出題要素を、規則として実装した。どれも京大の設問をエンジンだけで解かせて、答えと一致することを確かめてある。

| カード | 規則 | 出典 |
| --- | --- | --- |
| 小員環の水素化開環 | 三員環・四員環の C–C が1本切れる。小員環がいちばん残らない結合が切れる | 2025 III |
| 臭素付加（立体）・水素付加（立体） | Br₂ はアンチ付加、白金触媒の H₂ はシン付加。E/Z から生成物の立体異性体が決まる | 2024 III(b) |
| 立体異性体の数・光学活性 | 鏡像異性体・メソ体・シス-トランスを区別して数える | 2002 III・2019 IV |
| 硝酸酸化（糖）・炭素を1つ減らす反応 | フィッシャー投影のアルドースから、立体を保って変換 | 2019 IV |
| イミドの穏やかな加水分解 | C(=O)–N–C(=O) の C–N が1本だけ切れる（どちらかは決まらない） | 2019 III(b) |
| 選択的アセチル化 | 同じ物質量の無水酢酸では第一級 OH だけ | 2010 III(a) |
| ニトロ化・臭素化・塩素化・スルホン化・臭素水 | 配向性（-NH₂・-OH > -NHCOCH₃・-OR > アルキル > ハロゲン、メタ配向の基）と立体障害 | 2018 III・2016・2010(b)・2009・2004 |
| ニトロ基の還元・アセチル化・ジアゾ化と還元・ジアゾ化と加熱・ジアゾカップリング | 合成経路をたどる（m-ブロモトルエンの合成など） | 2018 III・2001 III |
| エーテルの水素化分解 | Ar–O–Ar' + H₂ → Ar–OH + Ar'–H（両方の向き） | 2016 III(b) |
| エタノール中・メタノール中の平衡、アセタールの加水分解 | 五員環・六員環をつくれるアルデヒドは環状アセタール、つくれないものはジアルキルアセタール | 2026 III |
| アセトンによる保護 | 1,2 または 1,3 の OH の組。OH が3つ以上なら近い組 | 2020 IV |
| メチル化分析 | すべての OH をメチル化してからグリコシド結合だけを加水分解 | 2026 IV |
| 水の付加（マルコフニコフ則） | H は H の多い炭素に | 2005・2002 |

このうち臭素水・ニトロ化・選択的アセチル化・アセトン保護・臭素付加・立体異性体の数は自動生成の手がかりにも使う。
これで、今までカードで区別できず出題できなかった断片（クレゾール・エチルフェノール、ヒドロキシ安息香酸、アミノ安息香酸など）も問題にできるようになった。
